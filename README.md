# Café CR

Prototipo de e-commerce para "Café CR" (café gestionado por IA en el campus ADEN), convertido a un proyecto React + Vite. Datos en `src/data.js` separados de la interfaz (`src/App.jsx`), para facilitar la futura integración con Google Sheets, APIs y agentes de IA.

## Cómo abrirlo

1. Abre esta carpeta en Visual Studio Code (File → Open Folder).
2. Abre la terminal (Terminal → Nueva terminal) y ejecuta:

   ```
   npm install
   npm run dev
   ```

3. Abre la dirección que te muestre la terminal (normalmente `http://localhost:5173`) en tu navegador.

## Estructura

- `src/data.js` — datos de ejemplo (productos, clientes, cupones), todos ficticios.
- `src/icons.jsx` — iconos SVG usados en la interfaz.
- `src/App.jsx` — toda la lógica y pantallas del prototipo.
- `src/main.jsx` — punto de entrada de React.

No necesitas escribir código a mano — Claude Code te va a ayudar con los próximos pasos (GitHub, Vercel, backend, pagos).
